## معالجة drizzle-kit

كان `drizzle-kit@0.31.10` يصرح بـ MIT في npm وpackage.json، بينما رخصة جذر مستودعه Apache-2.0، ولم يوجد نص MIT في أرشيف الإصدار أو شجرته المفحوصة. بقي [استفسار الناشر](https://github.com/drizzle-team/drizzle-orm/issues/6434) دون إجابة عند الفحص، فلم ننشئ نصًا أو نسبًا افتراضيًا للحقوق.

أُزيلت الحزمة وملف `drizzle.config.ts` وأمر `db:generate`، وحُذف 54 إدخالًا غير لازم من ملف التثبيت، دون إضافة حزمة أو تغيير نسخ الباقي. بقيت ملفات SQL الثلاثة وتعريفات المخطط، وهي كافية لتهيئة قاعدة جديدة. التطبيق يستعمل SQL مع D1، ولا يحتوي ناتج التشغيل على drizzle-kit أو drizzle-orm. يبقى drizzle-orm لتعريف المخطط مع ترخيص Apache المحفوظ. أي هجرة جديدة تحتاج SQL مراجعًا؛ لا تُعاد كتابة هجرة سبق تنفيذها.
